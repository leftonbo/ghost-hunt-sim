# 👻 おばけの追いかけっこシミュレーター

画面上のおばけ👻がニンゲンを追いかけて食べるのを見守るシミュレーターです。
食べられたニンゲンはおばけの体内でおばけに変えられて、新しいおばけとして飛び出します。
最終的に全員おばけになったらシミュレーション終了！

> かわいげのあるホラーがテーマ。怖いけどどこか楽しい雰囲気を大切にしています。

## 🎮 遊び方

1. `npm install` で依存パッケージをインストール
2. `npm run dev` で開発サーバーを起動
3. ブラウザで `http://localhost:5173/` を開く
4. 操作パネルでおばけ数・ニンゲン数・速度を調整
5. 「▶ 開始」ボタンを押す
6. おばけがニンゲンを追いかける様子を眺める
7. 全ニンゲンがおばけになったらクリア！
8. 設定パネルから言語を日本語 / 英語で切り替え可能

## 🕹️ 操作

| 操作 | 説明 |
| ------ | ------ |
| ▶ 開始 | シミュレーションを開始 |
| ⏸ 一時停止 | 一時停止 / 再開のトグル |
| 🔄 リセット | 初期状態に戻す |
| 言語切替 | 設定パネルから日本語 / 英語を即時切替 |
| 初期おばけ数 | 1〜10（デフォルト: 1） |
| 初期ニンゲン数 | 5〜200（デフォルト: 50） |
| ランタン数 | 0〜30（デフォルト: 7） |
| 速度 | 0.5x〜3.0x（デフォルト: 1.0x） |

## 👻 おばけの種類

- ノーマル: 近くのニンゲンを追いかけて捕食します。
- フェラル: ダッシュ中だけ捕食できる突進型です。
- すいこみ: コーン状の範囲でニンゲンを引き寄せます。
- べろべろ: 遠距離から舌を伸ばしてニンゲンを捕まえます。
- けむり: 遠距離に煙幕を投げ、弱ったニンゲンをゆっくり追い詰めます。

## 📋 情報表示

- 現在のおばけ数 / ニンゲン数

- 終了時メッセージ
- 現在言語に応じた UI 文言

## 🔧 技術仕様

- **ビルドツール**: Vite 8
- **言語**: TypeScript（strict モード）
- **スタイル**: CSS Modules
- **リンター**: ESLint + Prettier
- **i18n**: i18next（日本語 / 英語切替、localStorage 保存）
- 描画は Canvas API ベース（描画ライブラリ不使用）
- `requestAnimationFrame` ベースの 60fps ゲームループ
- update → draw の分離構造
- レスポンシブ対応（ウィンドウリサイズに追従）

## 🌍 言語切替

- 初回アクセス時はブラウザ言語が英語系なら英語、それ以外は日本語で開始
- 設定パネルの「言語」から日本語 / 英語を即時切替
- 選択した言語は `localStorage` に保存され、再読み込み後も維持
- 終了画面のメッセージや設定パネルの文言も切替対象

## 🧠 ニンゲンの逃走ロジック

- おばけ検知時は、反対方向の合成ベクトルに加えて横ステップを混ぜ、直線的すぎる逃走を抑制
- 角に追い詰められた度合い（corneredness）に応じて、逃走加速度と分離力を段階的に強化
- 壁回避は角で相反力が相殺されないよう片側を減衰し、停止しにくいように調整
- 壁反射時は内向きベクトルへ進行方向を再設定して、角での往復振動を軽減
